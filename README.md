# Emerald-Escapes

A three-page responsive website for a fictional travel company called Emerald Escapes, which specialises in holidays, short breaks and unique travel experiences across Ireland.

1. Home Page
The Home page should include:
•	An introduction to Emerald Escapes, including its story and target customers. 
•	A consistent colour scheme inspired by Ireland and travel. 
•	A hero banner with a suitable tagline, such as “Explore More. Discover Ireland.” 
•	A brief overview of the travel experiences offered. 
•	A clear link or button directing users to the Experiences page. 
2. Experiences Page
The Experiences page should:
•	Showcase at least 15 travel experiences or destinations.
•	Include options such as city breaks, coastal adventures, countryside escapes, family trips and cultural experiences.
•	Use CSS to create a card layout that adapts to desktop, tablet and mobile screens.
•	Display an image, location, short description, duration and price for each experience.
•	Include an interactive feature allowing users to filter experiences by:
o	Category, such as City, Coastal, Countryside or Family
o	Price range
•	Include hover effects on the experience cards.


3. Contact and Booking Enquiry Page
The page must include a form with the following fields:
•	Name 
•	Email 
•	Phone 
•	Query Type drop-down: 
o	Booking 
o	Payment 
o	General Information 
o	Other 
•	Message 
Apply client-side validation for:
•	Required fields 
•	Valid email format 
•	Valid phone number 
•	A minimum message length 
Use JavaScript or jQuery to display appropriate confirmation and error messages.
Other Requirements
•	The website must be responsive across desktop, tablet and mobile devices. 
•	Use CSS and media queries to make the website responsive. Bootstrap is optional.
•	Use separate external CSS and JavaScript files. 
•	Code must use appropriate commenting, formatting and indentation. 
•	All navigation links and interactive features must work correctly. 
•	Images should be suitable, properly sized and include meaningful alternative text.
